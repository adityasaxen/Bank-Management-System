# 🏦 Bank Management System

A Java-based Bank Management System developed as a Semester 3 project
to demonstrate core Java programming concepts and basic banking operations.

## 📌 About the Project

This project simulates basic banking operations through a Java-based
application. It was developed to strengthen my understanding of Java,
object-oriented programming, classes, interfaces, and application logic.

## ✨ Features

- User registration
- User login
- Customer management
- Deposit operations
- Withdrawal operations
- Banking activity management
- Exit/logout functionality

## 🛠️ Tech Stack

- Java
- Object-Oriented Programming
- Java Interfaces
- Java Classes
- IntelliJ IDEA
